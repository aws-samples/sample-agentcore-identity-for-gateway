# webchat/cognito-idc/
Browser GUIs for the **Cognito + IAM Identity Center** track: `obo_app.py` + `index.html` (port 8080), `oauth_app.py` + `oauth_index.html` (8081), `rbac_app.py` + `rbac_index.html` (8082). Each app loads its HTML from its own folder. Run locally with `infra/common/run.sh .venv/bin/python webchat/cognito-idc/<app>.py`; see [`../README.md`](../README.md).

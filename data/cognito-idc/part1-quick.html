Architecture: Quick → Cognito → Gateway → Cedar → Lambda

Amazon Quick is the OAuth client. It signs the user in to Amazon Cognito (authorization code + PKCE, with the RFC 8707 resource parameter) and stores that user's own access token. A Pre Token Generation trigger writes a roles claim from the user's Cognito groups. Quick then calls the AgentCore Gateway rsidc-mall-gateway directly as an MCP client; the Gateway validates the JWT and Policy in AgentCore (Cedar) decides per tool from roles. There is no AgentCore Runtime, no AgentCore Identity and no token exchange in this path. Quick can run in the same or a different AWS account (us-east-1); the connector only needs the Gateway URL.

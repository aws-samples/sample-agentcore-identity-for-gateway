架构：Quick → Entra ID → CloudFront → AgentCore Gateway → Lambda

Amazon Quick 让用户登录 Microsoft Entra ID，并通过自定义域名 mcp.agentzone.click 上的 CloudFront 调用 Gateway。 CloudFront 只负责响应 OAuth discovery（mcp-prm）；Gateway 校验 Entra token（CUSTOM_JWT）， Policy in AgentCore（Cedar）根据 roles claim 逐个工具做出授权决策。编号与图中的 Flow 图例一致。 实线 = 请求，虚线 = 仅做验证（JWKS）。

查看原图 · 实线 = 请求；虚线 = 依据 Entra JWKS 校验 token 签名（不做 token 交换）。CloudFront 只改写 OAuth discovery（mcp-prm + response headers policy）；授权在 Gateway 完成（CUSTOM_JWT + 基于 roles claim 的 Cedar）。
